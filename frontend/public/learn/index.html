Practical accounting example: Purchase to Payment

Illustrative perpetual inventory purchase: goods ₹10,000 plus eligible input GST 18%.

DocumentDebitCredit
Purchase Request / PO——
GRPOInventory ₹10,000GRPO Clearing ₹10,000
A/P InvoiceGRPO Clearing ₹10,000; Input GST ₹1,800Vendor ₹11,800
Outgoing PaymentVendor ₹11,800Bank ₹11,800

Actual postings vary by inventory method, tax configuration and account determination. Use a test database for exercises.
